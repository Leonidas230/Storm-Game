# Storm-Game
Generated by [Rojo](https://github.com/rojo-rbx/rojo) 7.7.1.

## Getting Started
To build the place from scratch, use:

```bash
rojo build -o "Storm-Game.rbxlx"
```

Next, open `Storm-Game.rbxlx` in Roblox Studio and start the Rojo server:

```bash
rojo serve
```

The main menu offers Rage, Flood, and Rain. Rage uses rig asset `82365423189386`, Flood uses `126251167185079`, and Rain uses `111723898522317`; each has a dedicated client animation script and its own movement, flight, hit, and attack animations. Rage and Rain use bows, while Flood uses a sword. Rage and Flood cycle through three attack animations; Rain uses its bow attack animation. The three characters share flight controls: double-tap Space while airborne to toggle flight; steer with WASD relative to the camera, ascend with Space, and descend with Left Ctrl. Hold E while flying to charge a ground dive; the character stays still as you aim with the camera and follow the floor marker. Releasing E early cancels the charge. Hold Shift to sprint. The landing marker clones a `Pointer` part from `PlayersArrow` or a `Pointer` found in Workspace or ReplicatedStorage; if none exists, it uses a fallback marker. The marker disappears when the dive launches. Landing starts a two-second recovery that locks movement and camera controls while shaking the camera. Weapon hits are checked and applied on the server.
